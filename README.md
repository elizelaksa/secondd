# Season 2 Decision Studio

This is a no-build static website. To deploy it:

1. Extract the ZIP contents into a new GitHub repository.
2. Commit and push `index.html`.
3. Import the repository into Vercel.
4. Choose **Other** as the framework preset and leave the build command blank.

Vercel will serve `index.html` automatically. All calculations run in the browser; no database, API key, or server configuration is needed.
